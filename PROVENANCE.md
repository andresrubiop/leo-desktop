# Public source provenance

Release preparation date: 2026-10-26. Base application: LEO 0.19.1, source commit `621a8c335c9e6ff2ff03ee04f3b46cffb8c2d8e0`.

The application modules, extension, vector illustrations, development scripts and synthetic test fixtures come from that version. The public README, architecture overview, verification notes, license and CI configuration were prepared for this distribution. No installed service or user setting is needed to read or test the source.

Personal photos and photo-derived raster sprites are not distributed. The procedural SVG illustrations are included. Private development instructions, the operational journal, account state and configuration are not included.

The modules in `leo/usage` and `leo/widget` retain their original MIT notices. Optional services and models are separately installed and retain their own terms. Cerveau itself is not bundled.

Development used AI coding assistants. Implementation claims are separated from unit tests and manual integration evidence; no model-performance number is inferred from the presence of source code.
